## Explicitly deferred (security / product)

- Unrestricted AI agents / MCP with OS power
- Plugin marketplace
- Taskbar / Explorer / Shell Extension / WorkerW / registry hacks
- Administrator elevation / auto-installers
- TimeTree “API” pretenses (use Web Widget if needed)
- Reimplementing a Classroom Widget UI

## Principle

Keep the ladder:

```
Intent → Command → Service → Validated target → Platform
```

Never give AI direct filesystem, PowerShell, or process control.
