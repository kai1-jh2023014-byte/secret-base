# Secret Base — v0.2 Roadmap (candidates)

These are **not** implemented in v0.1. Captured so future work stays intentional.

## Candidates

```
v0.2
├── AI Command (natural language → CreativeCommand / AiCommand)
├── Richer Project Context (for future AI)
├── Deeper Cursor integration (still no arbitrary shell)
├── GitHub integration (read-only first)
├── Spotify / YouTube Music official APIs (when credentials exist)
├── Notion data API (never fake TimeTree sync)
├── Multi-monitor polish
└── Richer workspace automation (still Command-gated)
```

## Explicitly deferred (security / product)

- Unrestricted AI agents / MCP with OS power
- Plugin marketplace
- Taskbar / Explorer / Shell Extension / WorkerW / registry hacks
- Administrator elevation / auto-installers
- TimeTree “API” pretenses (use Web Widget if needed)

## Principle for v0.2+

Keep the ladder:

```
Intent → Command → Service → Validated target → Platform
```

Never give AI direct filesystem, PowerShell, or process control.
